## StackPlus 3.1.3

### Fixes

- **Minecraft 26.3:** Fixed items in the per-item limit screen not being selectable. Minecraft 26.3 changed mouse button numbering, so left clicks were ignored.
- **Minecraft 26.3:** Fixed clicking and dragging in the color picker screen for the same reason.

### Notes

- This release only affects the Minecraft 26.3 build. Other versions are unchanged (3.1.2).
- Requires Fabric API. Mod Menu is recommended for opening the settings screen.
